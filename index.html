1.7.0

7 августа 2026
  • Проверка ranked-матчей вынесена в GitHub Actions: Cloudflare Worker больше не расходует общий анонимный лимит OpenDota.
  • Статус проверки обновляется автоматически; попытка сохраняется при временном лимите или незавершённом разборе реплея.
  • Неполная сборка засчитывается с экспоненциальным снижением: ×0,6 за каждый отсутствующий предмет.
  • Улучшенные предметы засчитываются за исходные компоненты, например Parasma — за Witch Blade.

1.6.1

7 августа 2026

  • Кнопка подтверждения получила серверный кулдаун: повторные клики и несколько вкладок не спамят внешние API.
