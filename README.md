# Dota Chaos Build

Статический генератор случайного героя и шестислотовой сборки Dota 2. Проект не требует сервера и готов к публикации на GitHub Pages.

## Что реализовано

- интерфейс в стилистике игрового HUD Dota 2;
- актуальная маркировка патча **7.41e**;
- загрузка героев и предметов из `odota/dotaconstants` с резервным локальным набором;
- отдельные кликабельные слоты Aghanim's Scepter и Aghanim's Shard;
- включённый по умолчанию режим случайного сапога в первом слоте;
- интерактивное рекурсивное дерево сборки предметов: каждый компонент можно открыть и разобрать дальше;
- предметы с дальнобойной механикой выдаются только ranged-героям;
- предметы с ближней механикой выдаются только melee-героям;
- Divine Rapier выпадает отдельным броском с вероятностью 0,35% на полную генерацию;
- закрепление отдельных слотов и переброс только свободных;
- «Контракт Рошана» — дополнительное условие на матч;
- точная ссылка на героя, предметы, контракт, настройку сапога и закреплённые слоты;
- адаптивная версия для телефона.

## Локальный запуск

Сборка не нужна. Можно открыть `index.html` напрямую, но для корректной работы Clipboard API удобнее запустить локальный сервер:

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий.
2. Загрузите в корень все файлы этого проекта, включая `.github/workflows/pages.yml` и `.nojekyll`.
3. В GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
5. Сделайте push в ветку `main`. Workflow автоматически опубликует сайт.

Также можно удалить workflow и выбрать публикацию напрямую из ветки `main` / корня репозитория.

## Обновление патча

Номер патча находится в начале `app.js`:

```js
const CONFIG = {
  patch: '7.41e',
  // ...
};
```

Данные героев и предметов загружаются с ветки `master` проекта `odota/dotaconstants`. Для полностью фиксированной версии замените `@master` в URL на конкретный commit SHA.

## Настройка вероятности Rapier

В `app.js`:

```js
rapierChance: 0.0035
```

`0.0035` соответствует 0,35% на одну полную генерацию.

## Ограничения по типу атаки

Списки находятся в `app.js`:

```js
const RANGED_ONLY = new Set([...]);
const MELEE_ONLY = new Set([...]);
```

Остальные предметы специально не фильтруются по ролям или атрибутам, чтобы сохранить смысл фанового рандома.
