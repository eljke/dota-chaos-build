# Dota Chaos Build

Dota 2 Random-генератор со статическим интерфейсом на GitHub Pages и отдельным Cloudflare Worker для подтверждённого ranked-режима.

## Возможности

- случайный герой и шестислотовая сборка;
- случайный сапог в первом слоте — опция включена по умолчанию;
- melee-предметы не выпадают ranged-героям и наоборот;
- редкий отдельный бросок Divine Rapier — 0,35%;
- рекурсивное дерево сборки предметов;
- исправление внутренних ключей Parasma, Battle Fury и Gleipnir;
- очистка некорректных циклических рецептов, включая Specialist's Array;
- 10 осмысленных модификаторов, которые можно доказать данными распарсенного матча;
- точный перенос сборки через код формата `DCB1-...`;
- совместимость со старыми ссылками и короткими seed-кодами;
- SEO-разметка, `robots.txt`, `sitemap.xml`, Open Graph и Schema.org;
- подключаемая статистика посещений через GoatCounter;
- автоматическое обновление патча и снимка `odota/dotaconstants` при каждом деплое и ежедневно;
- отдельный ranked-интерфейс без частичных замков: только полный серверный реролл всей сборки;
- анти-абуз таймер: матч должен начаться после выдачи последней ranked-сборки;
- отмена ranked-попытки со штрафом и коротким кулдауном;
- асинхронная проверка победы через GitHub Actions и OpenDota без запросов к OpenDota из Cloudflare Worker;
- частичный зачёт сборки: каждый отсутствующий предмет умножает очки на `0,6`;
- апгрейды засчитываются за исходные предметы сборки, включая Parasma вместо Witch Blade;
- Steam OpenID с никнеймом, аватаром и лидербордами Normal/Turbo в Cloudflare D1.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

Локально сайт попробует загрузить `data/*.json`, а при их отсутствии переключится на jsDelivr или GitHub Raw.

## GitHub Pages

В репозитории используется ветка `master`.

1. Загрузите все файлы в корень репозитория.
2. Откройте **Settings → Pages**.
3. Выберите **Source → GitHub Actions**.
4. Сделайте commit в `master`.
5. Следите за workflow **Sync Dota data and deploy GitHub Pages** во вкладке **Actions**.

Workflow перед публикацией:

1. скачивает свежие `heroes.json` и `items.json` из `odota/dotaconstants`;
2. проверяет официальный Dota 2 patchnotes datafeed и определяет последний номер gameplay-патча;
3. создаёт `data/meta.json`;
4. создаёт компактный `data/ranked-pool.json` для серверного генератора;
5. публикует полученный снимок на GitHub Pages.

## Ranked API

Worker настраивается через `wrangler.jsonc`, схема D1 хранится в `worker/migrations`. Максимальный результат считается как `round(1000 × сложность модификатора × 1.2 при строгом порядке / (полные рероллы + штрафы отмены + 1))`. Затем применяется множитель завершения сборки: `0,6^(6 − собранные предметы)`. Например, 6/6 даёт 100%, 5/6 — 60%, 4/6 — 36%, 3/6 — 21,6%. Штраф отмены сохраняется для выбранного режима до следующей подтверждённой победы. В лидерборд идёт сумма 10 лучших подтверждённых побед игрока; Normal и Turbo считаются отдельно.

```bash
npm install
npm test
npm run typecheck
npx wrangler d1 migrations apply dota-chaos-ranked --remote
npx wrangler secret put STEAM_API_KEY
npx wrangler secret put GITHUB_ACTIONS_TOKEN
npx wrangler secret put VERIFICATION_CALLBACK_SECRET
npm run worker:deploy
```

Для GitHub Actions добавьте в **Settings → Secrets and variables → Actions**:

- `VERIFICATION_CALLBACK_URL` — `https://dota-chaos-ranked-api.finflow-eljke.workers.dev/internal/verification-callback`;
- `VERIFICATION_CALLBACK_SECRET` — та же случайная строка длиной не менее 32 символов, которая сохранена в Worker;

`GITHUB_ACTIONS_TOKEN` — fine-grained GitHub token только для этого репозитория с разрешением **Actions: write**. Он нужен Worker, чтобы запускать `verify-ranked-match.yml`. `STEAM_API_KEY` используется для официального Steam Web API. Секреты нельзя добавлять в `wrangler.jsonc` или коммитить в репозиторий.

Для версии 1.7.0 сначала примените миграцию `0004_ranked_v170.sql`, настройте Worker и Actions secrets, затем задеплойте Worker. После публикации `data/ranked-pool.json` будет содержать рекурсивный список допустимых апгрейдов каждого предмета.

Также workflow запускается ежедневно по расписанию. Если внешний источник временно недоступен, браузер использует резервные CDN-источники и встроенный набор данных.

## Код сборки

Код `DCB1-...` содержит:

- seed;
- героя;
- шесть предметов;
- выбранный модификатор;
- режим обязательного сапога;
- закреплённые слоты.

Для импорта вставьте код в поле **«Импортировать код»** и нажмите **«Импорт»**. Полная ссылка в адресной строке передаёт те же данные.

Старый короткий seed также принимается, но его результат может меняться после обновления констант или списка модификаторов.

## Статистика уникальных посещений

GitHub Pages не предоставляет приложению собственную базу для подсчёта уникальных посетителей. В проект добавлена интеграция с GoatCounter — лёгкой аналитикой без cookies.

1. Создайте сайт на GoatCounter.
2. Откройте `analytics-config.js`.
3. Укажите короткий код сайта:

```js
window.DCB_ANALYTICS = {
  goatCounterCode: 'dota-chaos'
};
```

Для адреса `https://dota-chaos.goatcounter.com` кодом будет `dota-chaos`.

После деплоя статистика посещений, источников переходов, браузеров и экранов появится в панели GoatCounter. Чтобы показывать число визитов в футере сайта, включите в GoatCounter настройку публичного visitor counter.

## SEO

Основной адрес задан в:

- `index.html` — canonical, Open Graph и JSON-LD;
- `robots.txt`;
- `sitemap.xml`.

При переносе на другой домен замените `https://eljke.github.io/dota-chaos-build/` во всех трёх файлах. Наличие ключевых слов не гарантирует позицию в поиске: индексация зависит от возраста сайта, внешних ссылок, поведения посетителей и качества содержимого.
